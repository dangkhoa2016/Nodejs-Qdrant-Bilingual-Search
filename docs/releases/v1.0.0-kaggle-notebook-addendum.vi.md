> 🌐 Language / Ngôn ngữ: [English](v1.0.0-kaggle-notebook-addendum.md) | **Tiếng Việt**

addendum này ghi lại bản demo Kaggle tích hợp kho lưu trữ notebook được thêm vào sau khi xuất bản `v1.0.0` ban đầu kết thúc.

## Điểm khởi chạy canonical notebook

```text
notebooks/kaggle-cpu-fp16-production-demo.ipynb
```

notebook nhập từ GitHub, làm mới repository chính thức thành `/kaggle/working`, xác thực các đầu vào bất biến được đính kèm, khôi phục canonical 20K Qdrant snapshot mà không cần gieo hạt lại, khởi động CPU-FP16 runtime được chấp nhận ở chế độ chỉ cục bộ, chạy chấp nhận EN/VI ổn định, tùy chọn xuất bản một Quick Tunnel đã được xác thực và đóng gói bằng chứng đã được làm sạch.

## Cấu trúc liên kết công cộng được xác thực

```text
Cloudflare Quick Tunnel
  -> 127.0.0.1:8090 Bearer-auth gateway
  -> 127.0.0.1:3000 Node/Hono API

localhost-only:
  127.0.0.1:8001 Qwen3 embedding service
  127.0.0.1:6333 Qdrant
```

Các tuyến API công cộng yêu cầu Bearer token mỗi phiên. token vẫn nằm trong thư mục Kaggle runtime riêng tư và bị loại khỏi kho lưu trữ bằng chứng. Việc chấp nhận công khai gate yêu cầu rõ ràng một request chưa được xác thực để trả về HTTP `401`.

Tìm kiếm inference được giới hạn ở một request công khai đồng thời trong khi health/readiness vẫn phản hồi. Cổng cũng áp dụng danh sách tuyến đường cho phép, rate limit, giới hạn nội dung yêu cầu, ID request và timeout ngược dòng.

## Phạm vi chấp nhận

Triển khai cứng gates sử dụng EN Thái Lan, Tokyo VI, Bắc Kinh VI và âm tính dương tính giả theo địa lý Casablanca. Dạng viết hoa Fuji/Nhật Bản và Thái Lan-VI vẫn chỉ mang tính chất chẩn đoán.

Các dấu hiệu công khai/bằng chứng bắt buộc bao gồm:

```text
AUTH_GATEWAY=PASS
UNAUTHENTICATED_REQUEST=401
PUBLIC_TUNNEL_TARGET=http://127.0.0.1:8090
PUBLIC_TUNNEL=PASS
QDRANT_PUBLIC_EXPOSURE=NO
EMBEDDING_PUBLIC_EXPOSURE=NO
EVIDENCE_MANIFEST_PATH_MODE=RELATIVE
EVIDENCE_SHA256SUMS_SELF_ENTRY=NO
EVIDENCE_REEXTRACT_VERIFY=PASS
```

## Gate phát hành

Bản thân addendum này **không** yêu cầu thực thi Kaggle trực tiếp thành công. GitHub CI xác thực cấu trúc notebook, hành vi của đơn vị cổng, cú pháp trợ giúp và các hợp đồng cấu trúc liên kết công khai. Cần có Kaggle **Khởi động lại phiên → Chạy tất cả** cùng với bằng chứng được xem xét độc lập trước khi nhắm mục tiêu lại `v1.0.0` hoặc ghi đè ghi chú/nội dung GitHub Release công khai để xác nhận đường dẫn notebook này là đã được xác thực trực tiếp.
