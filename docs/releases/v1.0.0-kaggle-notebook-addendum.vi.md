## Điểm khởi chạy canonical notebook

```text
notebooks/kaggle-cpu-fp16-production-demo.ipynb
```

notebook nhập từ GitHub, làm mới repository chính thức thành `/kaggle/working`, xác thực các đầu vào bất biến được đính kèm, khôi phục canonical 20K Qdrant snapshot mà không cần gieo hạt lại, khởi động CPU-FP16 runtime được chấp nhận ở chế độ chỉ cục bộ, chạy chấp nhận EN/VI ổn định, tùy chọn xuất bản một Quick Tunnel đã được xác thực và đóng gói bằng chứng đã được làm sạch.

## Cấu trúc liên kết công cộng được xác thực

```text
Cloudflare Quick Tunnel
  -> 127.0.0.1:8090 Bearer-auth gateway
  -> 127.0.0.1:3000 Node/Hono API

localhost-only:
  127.0.0.1:8001 Qwen3 embedding service
  127.0.0.1:6333 Qdrant
```

Các tuyến API công cộng yêu cầu Bearer token mỗi phiên. token vẫn nằm trong thư mục Kaggle runtime riêng tư và bị loại khỏi kho lưu trữ bằng chứng. Việc chấp nhận công khai gate yêu cầu rõ ràng một request chưa được xác thực để trả về HTTP `401`.

Tìm kiếm inference được giới hạn ở một request công khai đồng thời trong khi health/readiness vẫn phản hồi. Cổng cũng áp dụng danh sách tuyến đường cho phép, rate limit, giới hạn nội dung yêu cầu, ID request và timeout ngược dòng.
