# v1.0.0 — Tìm kiếm ngữ nghĩa song ngữ với Qwen3-Embedding-4B + Qdrant
> 🌐 Language / Ngôn ngữ: [English](v1.0.0.md) | **Tiếng Việt**

## Tóm tắt

`v1.0.0` là bản phát hành công khai đầu tiên của `nodejs-qdrant-bilingual-search`: API tìm kiếm ngữ nghĩa địa lý mở tiếng Anh/Việt xây dựng với Node.js, Hono, Qdrant và Qwen3-Embedding-4B.

Profile di động được chấp nhận chạy embedding model với **Transformers / PyTorch / CPU / FP16**, đồng thời xuất vector công khai **Float32[2560]** đã chuẩn hóa qua transport `binary-f32`. Canonical Qdrant snapshot chứa 20.000 thực thể đã được xác minh.

> **Ghi chú tài liệu hậu-publication.** File này nằm trên nhánh `main` luôn có thể tiến về phía trước và được cập nhật sau khi `v1.0.0` đã freeze để tài liệu khớp với hồ sơ phát hành công khai cuối cùng. Danh tính phát hành bất biến vẫn là annotated tag `v1.0.0`; cập nhật tài liệu này không retarget tag và không thay đổi bất kỳ controlled release asset nào.

## Điểm nổi bật

- Semantic retrieval tiếng Anh/Việt trên canonical open-geography corpus 20K.
- `Qwen/Qwen3-Embedding-4B`, 2560 chiều, cosine distance.
- Kaggle CPU-FP16 portable runtime, model được load read-only từ `/kaggle/input`.
- Public embedding vector được chuẩn hóa `Float32[2560]`.
- CI tái tạo được trên Node 22 và Node 24.
- Python embedding-engine tests và real Qdrant integration tests.
- Dataset, seeding, verification và evidence tooling xác định.
- Repository governance với CODEOWNERS, hướng dẫn đóng góp/hỗ trợ song ngữ, security policy, issue/PR templates và dependency updates.
- Nhánh tham chiếu `runtime/true-fp32` riêng.

## Hạn chế đã biết

- Portable CPU demo/runtime, không phải low-latency GPU serving.
- Chưa có reranker.
- Chưa có hybrid sparse+dense retrieval.
- Chưa có RAG layer.
- Không tự động reseed runtime.
- Relation-style diagnostics có thể bộc lộ ranking limitations dù canonical semantic verification vẫn PASS.

## Công việc tham chiếu

`runtime/true-fp32` giữ lại triển khai CPU true-FP32 dựng sẵn đã được chứng minh dưới dạng nhánh kỹ thuật/tham chiếu. Canonical `v1.0.0` profile vẫn là CPU FP16 vì có memory headroom thực tế tốt hơn trên Kaggle.
