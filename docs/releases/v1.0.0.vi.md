# v1.0.0 — Tìm kiếm ngữ nghĩa song ngữ với Qwen3-Embedding-4B + Qdrant
> 🌐 Language / Ngôn ngữ: [English](v1.0.0.md) | **Tiếng Việt**

## Tóm tắt

`v1.0.0` là release công khai đầu tiên của `nodejs-qdrant-bilingual-search`: API tìm kiếm ngữ nghĩa địa lý mở tiếng Anh/Việt được xây dựng với Node.js, Hono, Qdrant và Qwen3-Embedding-4B.

profile di động được chấp nhận chạy embedding model với **Transformers / PyTorch / CPU / FP16** trong khi hiển thị **Float32[2560]** vectors trên `binary-f32` transport được chuẩn hóa. canonical Qdrant snapshot chứa 20.000 thực thể đã được xác minh.

## Điểm nổi bật của Release

- Truy xuất ngữ nghĩa tiếng Anh/tiếng Việt trên kho ngữ liệu địa lý mở canonical 20K.
- `Qwen/Qwen3-Embedding-4B`, 2560 kích thước, khoảng cách cosin.
- Kaggle CPU-FP16 runtime di động với read-only model đang tải từ `/kaggle/input`.
- embedding vectors công khai được chuẩn hóa `Float32[2560]`.
- Node.js CI có thể tái tạo trên Node 22 và Node 24.
- Kiểm tra công cụ nhúng Python và kiểm tra tích hợp Qdrant thực.
- Tập dữ liệu xác định, seeding, công cụ xác minh và bằng chứng.
- Kỹ thuật/tham chiếu `runtime/true-fp32` riêng biệt branch.

## Kiến trúc

```text
read-only Qwen3-Embedding-4B model in /kaggle/input
        ↓
Python FastAPI embedding service
        ↓
normalized Float32[2560] / binary-f32
        ↓
Node.js + Hono search API
        ↓
Qdrant canonical 20K collection
```

endpoints cục bộ mặc định:

```text
embedding : 127.0.0.1:8001
Node/Hono : 127.0.0.1:3000
Qdrant    : 127.0.0.1:6333
```

```text
device               = cpu
accelerator          = cpu
internal dtype       = float16
dimension            = 2560
public vector dtype  = float32
transport            = binary-f32
```

Đường ống chính xác:

```text
FP16 model forward
→ last-token pooling
→ cast pooled tensor to Float32
→ Float32 L2 normalization
→ Float32[2560] public vector
→ binary-f32 transport
```

## Khả năng tái tạo

Khởi động Canonical Kaggle CPU-FP16:

```bash
export QDRANT_STORAGE_PATH=/kaggle/working/qdrant-bilingual-search/qdrant-data
bash scripts/kaggle/run-qwen3-transformers-fp16-cpu.sh
```

Trình bao bọc phân giải model read-only từ `/kaggle/input`, thực thi hợp đồng CPU-FP16 được chấp nhận, cho phép tải ngoại tuyến và khởi chạy vòng đời sản xuất-bản demo.

Các lệnh xác minh:

```bash
npm run verify:canonical-config
npm run verify:semantic-index -- 20000
npm run seed:status -- --once --expected 20000
npm test
```

## Những hạn chế đã biết

- CPU demo/runtime di động, không phục vụ GPU có độ trễ thấp.
- Không có người xếp hạng lại.
- Không có truy xuất thưa thớt + dày đặc kết hợp.
- Không có lớp RAG.
- Không có khả năng gieo hạt runtime tự động.
- Chẩn đoán kiểu quan hệ có thể bộc lộ các giới hạn xếp hạng ngay cả khi quá trình xác minh ngữ nghĩa canonical vượt qua.

## Công việc tham khảo

`runtime/true-fp32` giữ lại triển khai CPU true-FP32 dựng sẵn đã được chứng minh dưới dạng branch kỹ thuật/tham chiếu. canonical `v1.0.0` profile vẫn là CPU FP16 vì nó cung cấp khoảng trống bộ nhớ thiết thực hơn trên Kaggle.
