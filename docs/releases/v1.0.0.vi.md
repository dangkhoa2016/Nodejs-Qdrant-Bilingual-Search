# v1.0.0 — Tìm kiếm ngữ nghĩa song ngữ với Qwen3-Embedding-4B + Qdrant
> 🌐 Language / Ngôn ngữ: [English](v1.0.0.md) | **Tiếng Việt**

## Tóm tắt

`v1.0.0` là release công khai đầu tiên của `nodejs-qdrant-bilingual-search`: API tìm kiếm ngữ nghĩa địa lý mở tiếng Anh/Việt được xây dựng với Node.js, Hono, Qdrant và Qwen3-Embedding-4B.

profile di động được chấp nhận chạy embedding model với **Transformers / PyTorch / CPU / FP16** trong khi hiển thị **Float32[2560]** vectors trên `binary-f32` transport được chuẩn hóa. canonical Qdrant snapshot chứa 20.000 thực thể đã được xác minh.

## Lịch sử và nguồn gốc bản phát hành

Lịch sử repository đã được tái cấu trúc để dễ review hơn sau lần phát hành `v1.0.0` ban đầu. Tag ban đầu trỏ tới lịch sử cũ. Sau khi dòng lịch sử `main` đã tái cấu trúc được xác thực độc lập, `v1.0.0` được retarget tới commit hoàn tất tài liệu cuối cùng trong dòng lịch sử đó.

Bằng chứng Kaggle production-demo sạch ngày 2026-08-31 vẫn hợp lệ đối với source commit đã tái cấu trúc `b316619ad94947571e91124adfe96071bbd1f255` và tree `ff28454332cf976d1fb8fb17262924b09ca92cd2`. Bằng chứng này được giữ lại như bằng chứng qualification lịch sử và không được đổi nhãn thành bằng chứng cho một release tip được rewrite về sau.

Chính sách publication cuối cùng của `v1.0.0` gắn notebook canonical với annotated tag `v1.0.0` thay vì nhánh `main` luôn thay đổi. Notebook fail-closed nếu checkout không resolve tới commit của annotated tag đó. Runtime-evidence artifact được kiểm soát cuối cùng được định nghĩa là evidence ZIP tạo bởi một lần Kaggle **Restart Session → Run All** mới từ chính xác frozen tag target. Timestamp và SHA-256 của evidence được ghi trong GitHub Release và release manifest dạng máy đọc được sau khi review độc lập, thay vì hard-code trong tài liệu source này trước khi lần chạy tồn tại.

Các archive **Source code (zip)** và **Source code (tar.gz)** do GitHub tự sinh trực tiếp từ annotated tag `v1.0.0` và nằm ngoài checksum manifest của các custom artifact được kiểm soát.

## Điểm nổi bật của Release

- Truy xuất ngữ nghĩa tiếng Anh/tiếng Việt trên kho ngữ liệu địa lý mở canonical 20K.
- `Qwen/Qwen3-Embedding-4B`, 2560 kích thước, khoảng cách cosin.
- Kaggle CPU-FP16 runtime di động với read-only model đang tải từ `/kaggle/input`.
- embedding vectors công khai được chuẩn hóa `Float32[2560]`.
- Node.js CI có thể tái tạo trên Node 22 và Node 24.
- Kiểm tra công cụ nhúng Python và kiểm tra tích hợp Qdrant thực.
- Tập dữ liệu xác định, seeding, công cụ xác minh và bằng chứng.
- Repository governance với CODEOWNERS, hướng dẫn đóng góp/hỗ trợ song ngữ, security policy, issue/PR template và cấu hình cập nhật dependency.
- Kỹ thuật/tham chiếu `runtime/true-fp32` riêng biệt branch.

## Kiến trúc

```text
read-only Qwen3-Embedding-4B model in /kaggle/input
        ↓
Python FastAPI embedding service
        ↓
normalized Float32[2560] / binary-f32
        ↓
Node.js + Hono search API
        ↓
Qdrant canonical 20K collection
```

endpoints cục bộ mặc định:

```text
embedding : 127.0.0.1:8001
Node/Hono : 127.0.0.1:3000
Qdrant    : 127.0.0.1:6333
```

### Bằng chứng publication exact-tag cuối cùng

Đối với lần refresh publication cuối cùng, notebook canonical checkout annotated tag `v1.0.0`, xác minh `HEAD` bằng commit của tag, yêu cầu Git status sạch, restore cùng canonical snapshot 20K mà không reseed, rồi thu thập evidence ZIP mới. Timestamp và digest của final evidence được chủ động ghi trong GitHub Release và release manifest sau khi lần chạy exact-tag đó được review độc lập.

Vì public tunnel tùy chọn không bắt buộc cho core local release gate, `AUTHENTICATED_PUBLIC_DEMO=NOT_RUN` vẫn là kết quả được ghi nhận hợp lệ khi tunnel được chủ động tắt. Hành vi gateway và public topology vẫn là các contract được kiểm thử trong CI.

## Khả năng tái tạo

Khởi động Canonical Kaggle CPU-FP16:

```bash
export QDRANT_STORAGE_PATH=/kaggle/working/qdrant-bilingual-search/qdrant-data
bash scripts/kaggle/run-qwen3-transformers-fp16-cpu.sh
```

Trình bao bọc phân giải model read-only từ `/kaggle/input`, thực thi hợp đồng CPU-FP16 được chấp nhận, cho phép tải ngoại tuyến và khởi chạy vòng đời sản xuất-bản demo.

Các lệnh xác minh:

```bash
npm run verify:canonical-config
npm run verify:semantic-index -- 20000
npm run seed:status -- --once --expected 20000
npm test
```

## Công việc tham khảo

`runtime/true-fp32` giữ lại triển khai CPU true-FP32 dựng sẵn đã được chứng minh dưới dạng branch kỹ thuật/tham chiếu. canonical `v1.0.0` profile vẫn là CPU FP16 vì nó cung cấp khoảng trống bộ nhớ thiết thực hơn trên Kaggle.
