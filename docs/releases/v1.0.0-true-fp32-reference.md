## Reference profile

This branch is an **alternative / reference runtime profile**. It is **not** the
default public production/demo runtime. The canonical `main` branch uses the
Transformers / PyTorch / CPU / **FP16** runtime with public vectors
`Float32[2560]`; see the FP16 release note on `main`.

The true-FP32 profile is a proven reference implementation:

```text
model               = Qwen/Qwen3-Embedding-4B
backend             = prebuilt true-FP32
implementation      = python-fastapi
runtime             = pytorch-cpu
device              = cpu
internal dtype      = float32 (true, verified)
dimension           = 2560
public vector dtype = float32
transport           = binary-f32
canonical Qdrant    = knowledge_entities_qwen3_4b_text_v21
```

## Honest demo limitation (preserved)

The historical strict one-shot demo acceptance did **not** pass. The first probe
(`en-thailand`) was sent once with a configured 120-second client boundary and
timed out. This limitation is preserved truthfully and is **not** reclassified:

```text
STRICT_ONE_SHOT_DEMO_ACCEPTANCE = FAILED
STRICT_CORRECTIVE_RESULT        = DEMO_CAPTURE_REGRESSION
STRICT_CORRECTIVE_RETRY         = NO
STRICT_CORRECTIVE_ROOT_CAUSE    = NOT_ISOLATED
```

See [docs/PORTFOLIO_EVIDENCE.md](../PORTFOLIO_EVIDENCE.md) and
[docs/kaggle-qwen3-embedding-4b-true-fp32-variation.md](../kaggle-qwen3-embedding-4b-true-fp32-variation.md)
for full runtime provenance and evidence.

## Reproducibility / hardening

- Hono pinned to the patched `4.12.34`.
- Clean installs use `npm ci --ignore-scripts` on the Node 22/24 matrix.
- Deterministic seed-process detection is safe on Node 24 (never trusts a generic
  `MainThread` comm value; verifies the real executable through procfs).
- `npm audit` and `npm audit --omit=dev` are clean (0 vulnerabilities).
