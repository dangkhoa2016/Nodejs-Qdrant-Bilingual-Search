This addendum records the repository-integrated Kaggle production-demo notebook added after the original `v1.0.0` publication closeout.

## Canonical notebook entry point

```text
notebooks/kaggle-cpu-fp16-production-demo.ipynb
```

The notebook imports from GitHub, refreshes the official repository into `/kaggle/working`, validates attached immutable inputs, restores the canonical 20K Qdrant snapshot without reseeding, starts the accepted CPU-FP16 runtime in local-only mode, runs stable EN/VI acceptance, optionally publishes an authenticated Quick Tunnel, and packages sanitized evidence.

## Authenticated public topology

```text
Cloudflare Quick Tunnel
  -> 127.0.0.1:8090 Bearer-auth gateway
  -> 127.0.0.1:3000 Node/Hono API

localhost-only:
  127.0.0.1:8001 Qwen3 embedding service
  127.0.0.1:6333 Qdrant
```

Public API routes require a per-session Bearer token. The token remains in the private Kaggle runtime directory and is excluded from the evidence archive. The public acceptance gate explicitly requires an unauthenticated request to return HTTP `401`.

Search inference is limited to one concurrent public request while health/readiness remain responsive. The gateway also applies a route allowlist, rate limit, request-body limit, request IDs, and an upstream timeout.

## Acceptance scope

Hard deployment gates use Thailand EN, Tokyo VI, Beijing VI, and the Casablanca geographic false-positive negative. Fuji/Japan and Thailand-VI capital-form remain diagnostic-only.

## Publication gate

This addendum does **not** by itself claim a successful live Kaggle execution. GitHub CI validates notebook structure, gateway unit behavior, helper syntax, and public-topology contracts. A clean Kaggle **Restart Session → Run All** plus independently reviewed evidence is required before retargeting `v1.0.0` or overwriting the public GitHub Release notes/assets to claim this notebook path as live-validated.
